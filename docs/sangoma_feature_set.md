# Sangoma Target Feature Set Proposal

## 1. Core Prediction Categories
*   **Energy (High Urgency):** Eskom Loadshedding Stages (e.g., "Stage 0 Streak", "Will Stage 6 return by July?").
*   **Macro-Economy:** ZARP/USD exchange rate volatility, SARB Repo Rate decisions, Inflation (CPI) targets, and ZARONIA benchmark shifts.
*   **Politics & Policy:** Election outcome probabilities, Legislative milestones (e.g., "NHI Bill signing date").
*   **Hyper-Local:** Rainfall levels in drought-prone areas, Municipal service delivery milestones.

## 2. Product Experience
*   **ZARP Integration:** Primary currency for all trades. Using a ZAR-pegged stablecoin eliminates forex friction and allows for easy local banking on-ramps.
*   **Mobile-Optimized PWA:** Fast, lightweight interface designed for South African network conditions (Edge/3G/4G).
*   **Tiered FICA Onboarding:** Simplified KYC for entry-level users to reduce friction while maintaining full regulatory compliance.
*   **Reputation System:** Genesis Soulbound NFTs for "Pioneer" cohort, granting voting weight in the Sangoma Council.

## 3. Trust & Settlement
*   **Hybrid Matching Engine:** High-performance off-chain matching with verifiable on-chain settlement on Polygon POS.
*   **UMA Optimistic Oracle:** Automated resolution for data-driven markets using global and local data feeds.
*   **Sangoma Council:** Human-in-the-loop resolution for complex qualitative local events.
*   **Regulatory Reporting:** Automated real-time dashboard for IFWG sandbox oversight.
